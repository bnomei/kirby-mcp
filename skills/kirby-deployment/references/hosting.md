# Hosting platforms

One row per host. Add a row only with facts checked in the host's own docs, and link them. A host gets a reference file of its own only when its workflow differs too much for one row.

| Host                    | Recognise by                                             | Code deployment                               | What survives a deployment                                                                            | Content sync                              | Docs                                                                                                                        |
| ----------------------- | -------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| fortrabbit              | `.fortrabbit/deploy.yml`, `.fortrabbit/environments.yml` | Git push through the GitHub App, or rsync     | The Kirby software template excludes `content`, `media`, `site/accounts`, `site/sessions` and `data/` | `frbit files pull/push` or rsync over SSH | [Kirby guides](https://docs.fortrabbit.com/guides/kirby), see `fortrabbit.md`                                               |
| Dokku                   | A `dokku` git remote                                     | Git push, built with the Heroku PHP buildpack | Only mounted persistent storage                                                                       | Into the mounted storage on the server    | [Kirby cookbook: Dokku](https://getkirby.com/docs/cookbook/development-deployment/git-based-deployment-with-dokku)          |
| FTP from GitHub Actions | A workflow with an FTP deploy action                     | Upload of the changed files on push           | Whatever the action does not upload or delete                                                         | FTP or SFTP                               | [Kirby cookbook: Git-based FTP deploys](https://getkirby.com/docs/cookbook/development-deployment/git-based-ftp-deployment) |
| VPS or shared hosting   | SSH or FTP access, no host files                         | rsync, SFTP or a release tool                 | What you exclude                                                                                      | rsync                                     | `generic.md`                                                                                                                |
