# kirbyuse

## Meaning

kirbyuse provides Panel composables and typings. Use kirbyuse 2.x for Kirby 6 and Vue 3; legacy 1.x targets Kirby 4/5. Bundle kirbyuse and leave Vue external: the stock Panel maps `vue`, not `kirbyuse`.

## In prompts (what it usually implies)

- "Use kirbyuse" means importing compatible composables into the plugin build; see `kirby://kb/panel/tooling-kirbyuse` before changing loaders.

## Example

```js
import { usePanel, useContent } from 'kirbyuse';
```
